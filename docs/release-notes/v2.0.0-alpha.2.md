# Release notes — v2.0.0-alpha.2

Field Redactor **2.0.0-alpha.2** continues the npm **2.0.0** prerelease line with **safe-by-default construction** (plan option A). It is **not** published to npm (prerelease tags are skipped by the publish workflow).

**Upgrade from 2.0.0-alpha.1:** Empty `new FieldRedactor()` / `{}` now throws. Pass at least one explicit rule list (or use `createSafe` / the builder).

## Highlights

| Area | Change |
| --- | --- |
| **Constructor** | Requires explicit rules; same bar as `createSafe` |
| **Warnings** | Removed “All values will be redacted…” empty-config warning |
