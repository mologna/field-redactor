# Release notes — v2.0.0-alpha.3

Field Redactor **2.0.0-alpha.3** continues the npm **2.0.0** prerelease line by **shrinking the public type surface**. It is **not** published to npm (prerelease tags are skipped by the publish workflow).

**Upgrade from 2.0.0-alpha.2:** If you imported any of the removed `@internal` types from `field-redactor`, switch to the supported public types below.

## Highlights

| Area | Change |
| --- | --- |
| **Exports** | Dropped incidental `@internal` re-exports from the package root |

### Removed from `import … from 'field-redactor'`

- `JsonFunction`
- `JsonLeafValue`
- `RedactablePrimitive`
- `RedactedPrimitive`
- `SecretSpecifierValue`
- `TraversableJson`

Prefer `JsonValue`, `JsonObject`, `JsonArray`, `JsonPrimitive`, `RedactableInput`, `RedactorInput`.

## Planned breaking themes

All themes from [docs/plans/2.0.md](../plans/2.0.md) are in the alpha line through **alpha.3**; housekeeping in **[alpha.4](v2.0.0-alpha.4.md)**; package cut is **[2.0.0](v2.0.0.md)** (tag/publish remaining).
