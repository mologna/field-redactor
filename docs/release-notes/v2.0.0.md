# Release notes — v2.0.0

Field Redactor **2.0.0** is the first published major after the **1.6.x** line. It finishes Opaque/Remove naming, requires explicit construction rules, shrinks incidental type exports, and aligns dry-run vocabulary with Remove.

This document is **not** the historical internal milestone [`2.0.0.md`](2.0.0.md) (pre-1.3 archaeology, never on npm).

**Upgrade from 1.6.3:** Follow [Migration 1.6 → 2.0](../guides/migration-1.6-to-2.0.md). Prereleases **alpha.1**–**alpha.4** tracked the work on `chore/2x-major` before this cut.

## Highlights

| Area | Change |
| --- | --- |
| **Naming** | Only Opaque/Remove config and enum names; Full/Delete aliases removed |
| **Dry-run** | `removedPaths` / `action: 'remove'` |
| **Constructor** | Empty config throws (same bar as `createSafe`) |
| **Exports** | Incidental `@internal` types no longer re-exported from the package root |

## Breaking changes

### Opaque / Remove only

| Removed | Use |
| --- | --- |
| `fullSecretKeys` / `deleteSecretKeys` | `opaqueSecretKeys` / `removeSecretKeys` |
| `CustomObjectMatchType.Full` / `.Delete` | `.Opaque` / `.Remove` |
| Builder `.delete()` | `.remove()` |

### Dry-run vocabulary

| Before | After |
| --- | --- |
| `deletedPaths` | `removedPaths` |
| `action: 'delete'` | `action: 'remove'` |

### Safe-by-default construction

`new FieldRedactor()` / `{}` throws `FieldRedactorConfigurationError` unless at least one explicit rule list is non-empty.

### Public type surface

No longer exported from `field-redactor`: `JsonFunction`, `JsonLeafValue`, `RedactablePrimitive`, `RedactedPrimitive`, `SecretSpecifierValue`, `TraversableJson`.

## Unchanged

Path rules, value patterns, copy-on-write, sync APIs, and root-only package `exports`.

**Schema-only configs** still shallow-redact unmatched keys (same as 1.6). Pair `customObjects` with explicit key rules, or set `secretKeys: []`. See [Anti-patterns](../guides/anti-patterns.md#schema-only-config-still-redacts-unmatched-keys).
