# Release notes — v2.0.0-alpha.1

Field Redactor **2.0.0-alpha.1** is a **prerelease** toward the npm **2.0.0** major. It ships the Opaque/Remove naming break and dry-run Remove vocabulary. It is **not** published to npm: tags like `v2.0.0-alpha.1` are skipped by the publish workflow (only `vMAJOR.MINOR.PATCH` publishes).

This is **not** the historical internal git milestone documented as [`2.0.0.md`](2.0.0.md).

**Upgrade from 1.6.3 (from git / local install):** migrate Full/Delete aliases and dry-run `deletedPaths` / `action: 'delete'` as in this release. Later alphas: **[2.0.0-alpha.2](v2.0.0-alpha.2.md)** (constructor), **[2.0.0-alpha.3](v2.0.0-alpha.3.md)** (`@internal` exports).

## Highlights

| Area | Change |
| --- | --- |
| **Naming** | Only `opaqueSecretKeys` / `removeSecretKeys` / Opaque / Remove; legacy Full/Delete aliases removed |
| **Dry-run** | `removedPaths` and `action: 'remove'` |
| **Publish guard** | Exact `vX.Y.Z` tags only |

## Still planned for 2.0.0
